# auto-sign

自用签到工具，支持常去的论坛获取积分和明日方舟森空岛

## Website

- Chiphell（签到）
- 天雪（模拟下载字幕）
- 花火学园（签到）
- 天使动漫（打工、签到）
- 心动日剧（签到）
- PSNINE（签到）
- 明日方舟（游戏签到，支持多账号）

## Usage

将 `config.example.json` 修改为 `config.json`，并填写 cookies 或 token。未填写的签到项目会自动跳过
